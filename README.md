# روت الإيموجي — iOS Emoji Root (النسخة النهائية)

مدير موديل خط **iOS 26.4 / Unicode 17** للأجهزة المفعّل عليها Root مسبقاً (KernelSU / APatch / Magisk).
يعمل **أوفلاين بالكامل**: بلا حسابات، بلا خوادم، وبلا صلاحية `INTERNET` (الـ CI يفحص ذلك ويفشل لو ظهرت).
لا يفعّل Root ولا يحتوي أي استغلال ثغرات (لا DFRoot ولا DirtyFrag).

## بنية المشروع: كل شيء في الجذر (مثل بيان)

لا يوجد `lib/` ولا `android/` ولا `assets/` في المستودع. ملفات Dart وKotlin والخطوط والموديل كلها في الجذر،
والبناء (`.github/workflows/build.yml`) يولّد هيكل أندرويد بـ `flutter create` ثم يشغّل `prepare_android.py` الذي:
يضع Kotlin في مساره، يكتب الـ Manifest (بلا صلاحيات)، يطبّق الثيم الداكن لشاشة البدء، يولّد الأيقونة من `icon.png`،
ويربط مفتاح التوقيع. المجلد الوحيد المتبقي `.github/workflows/` لأن GitHub يشترطه.

| الملف | الوظيفة |
|---|---|
| `main/app/home_screen/settings_screen/...dart` | الواجهة (RTL، خط Tajawal، ثيم داكن) |
| `side_drawer.dart` / `app_dialogs.dart` | القائمة الجانبية (على اليسار، بتصميم قائمة بيان) ونوافذها |
| `strings.dart` | النصوص بلغتين (عربي/إنجليزي، والإنجليزية وهمية حالياً) |
| `logo.dart` | شعارات القنوات وأعلام اللغات |
| `root_controller.dart` | منطق Root والتثبيت والسجل (يُحفظ على القرص) |
| `MainActivity.kt` / `RootUtils.kt` | الجسر: `su`، تثبيت/إزالة الموديل، استيراد الخط |
| `ios_emoji.zip` | هيكل الموديل بلا خط (راجع «ملف الخط») |
| `icon.png` | أيقونة بخلفية شفافة؛ استبدلها بأيقونتك وسيُولَّد كل شيء تلقائياً |
| `prepare_android.py` | تجهيز مشروع أندرويد وقت البناء |

## ملف الخط

الخط **لا يُرفق في المشروع ولا في الـ APK**. `ios_emoji.zip` هيكل صغير بلا خط (فيه `NotoColorEmoji.ttf` بحجم 0 كقالب للدمج).
يُرفق الخط من زر **«إرفاق ملف الخط»** داخل التطبيق: ملف `.ttf` يُدمج تلقائياً داخل الموديل، أو موديل `.zip` جاهز بالمعرّف `iOS26.4Unicode17`.
لا حاجة لإعادة البناء عند تغيير الخط. يمنع التطبيق التثبيت حتى يُرفق خط حقيقي.

## ما أُخذ من كل نسخة

- **ChatGPT (الأساس):** منطق Root كاملاً، تحذيرات السكربتات والـ Metamodule، تعطيل الموديلات للطوارئ، إعادة تشغيل الواجهة.
- **Claude:** الانتقالات الناعمة، حركة دخول البطاقات، ثيم شاشة البدء الداكن، الأيقونة التكيفية.
- **بيان:** تسطيح الملفات في الجذر وتجهيز أندرويد وقت البناء، التوقيع بمفتاح ثابت، سجل يُحفظ على القرص، `file_picker` لاستيراد الملفات، نفس إصدارات Flutter والمكتبات المجرَّبة.

## الإصدار 2.1.0

- قائمة جانبية منسوخة من بيان، وزر لغة (عربي/إنجليزي) يُحفظ ويبدّل فوراً.
- شاشة رئيسية مبسّطة: حالة الروت، زر واحد (طلب الروت ← إرفاق الخط ← التثبيت)، وفحص تلقائي عند الفتح.

## تحسينات وإصلاحات

- دعم APatch، وبحث عن `ksud`/`apd` في المسارات المعروفة حتى لو لم تكن في `PATH`.
- منع تثبيت خط فارغ، واستيراد خط/موديل من داخل التطبيق، وزر إعادة التثبيت بعد الاستيراد.
- سجل دائم مع زر مسح، وإعدادات تُحفظ بملف JSON (بلا مكتبات إضافية).
- إصلاح أخطاء في سكربتات الموديل: `local x = "..."` (خطأ صياغة في `service.sh` يعطّل دالتين)، و`force_stop_app "PKG"` بدل `"$PKG"`، و`chmod "$system"` بدل الهدف الصحيح.
- الاعتماد على مكتبتين فقط (`url_launcher` و`file_picker`) بدل خمس.

## البناء

1. ارفع محتويات المجلد إلى مستودع GitHub (الفرع `main`) واترك الملفات في الجذر.
2. التوقيع الثابت (موصى به كي تتحدّث النسخ فوق بعضها): أنشئ مفتاحاً مرة واحدة
   `keytool -genkeypair -keystore emoji.jks -alias emoji -keyalg RSA -keysize 2048 -validity 10000 -storepass كلمة_السر -keypass كلمة_السر`
   ثم أضف أسرار المستودع: `EMOJI_KEYSTORE_BASE64` (ناتج `base64 -w 0 emoji.jks`) و`EMOJI_KEYSTORE_PASSWORD` (واختيارياً `EMOJI_KEY_ALIAS`، الافتراضي `emoji`). بدونها يُبنى APK بمفتاح تجريبي.
3. شغّل Workflow **Build Emoji Root APK**، ونزّل `emoji-root-arm64` من Artifacts.

## تحقق

لا يتوفر Flutter/Dart في بيئة الإنشاء، فلم يُشغَّل `flutter build` هنا. كُتب الكود بنفس إصدارات وأنماط مشروع بيان الذي يُبنى عندك، وملفات Kotlin وسكربت التجهيز دُقّقت يدوياً. أول تشغيل للـ Workflow هو الاختبار الفعلي؛ إن ظهر خطأ أرسل لي سجل الخطوة الفاشلة.

متطلبات الجهاز: Android 7+ (arm64)، Root مفعّل مسبقاً، ولـ KernelSU الحديث يلزم Metamodule (مثل `meta-overlayfs`) كي يُركَّب مجلد `system`.
